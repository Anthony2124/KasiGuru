To maintain visual cohesion across the entire app, include these style parameters in your image generation prompts:

- **Art Style**: *Modern 3D Vector Isometric / Flat Vector Illustration with smooth gradients*.

## 🛠️ How to Export & Install Generated Assets

1. Generate your images using the prompts above.
2. Remove any background using a background remover tool (*or export as transparent PNG*).
3. Resize the images to the recommended dimensions:
   - **Characters & Heroes**: `512 × 512 px`
   - **Badges & Categories**: `256 × 256 px`
4. Save the files into your project's drawable folder:
   ```
   C:\KasiGuru\KasiGuru-main\app\src\main\res\drawable\
   ```
5. Rebuild your Android app with `.\gradlew assembleDebug`!
