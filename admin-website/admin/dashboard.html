Clear moderation queues

Deletes every pending and rejected word submission, literature submission, and issue report. Words already approved into the dictionary are unaffected.

Full database reset

Clearing learner progress, leaderboard rows, device tokens and security questions is deliberately not available here. Those documents are owner-writable only, so that a compromised admin session cannot rewrite anyone's learning record. A full reset runs from the operator machine with the service-account key: 

node functions/backup_firestore.js <service-account.json>
node functions/reset_firestore.js <service-account.json> --mode=learner
node functions/reset_firestore.js <service-account.json> --mode=factory --from=<backup-dir>

Both modes are a dry run until --confirm=<projectId> is passed. See docs/BACKUP_AND_RESET.md.
