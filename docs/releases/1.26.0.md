- Pronunciations now come with the app: every recorded word plays offline, and keeps playing when the server is busy. Only words recorded again since this update are downloaded. The app is a larger download because of this.
- Game hints: Word Search shows what each word still to find means, Word Wheel's "Show meanings" tells you what the hidden words mean and how long they are, and Sentence Order shows what the sentence's words mean.
- A word with no example sentence now lets you add one. A verifier checks it first, then it appears on the word's page, in lessons and in the sentence games.
- Home has a new "Help the dictionary" section with Add a word and Report an issue.
- The learning path is divided into its topic sections again. Since 1.24, new installs showed every lesson in one long section.
- Words removed or corrected in the dictionary no longer stay behind in the Library as a second entry with no recording. The app downloads the dictionary once more after this update to clear them.
- Edit profile now scrolls, so the address field and Save are always reachable, even with the keyboard open. Its back arrow asks before discarding your changes.
- The leaderboard refreshes at most every three minutes, so the app uses fewer server reads and keeps working all day.
